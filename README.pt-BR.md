# Perfil da organização Gravewright

[English](README.md) · [Português (Brasil)](README.pt-BR.md)

Este repositório mantém a apresentação pública da [organização Gravewright](https://github.com/Gravewright).

- [`profile/README.md`](profile/README.md) é o perfil principal em inglês, exibido na página inicial da organização.
- [`profile/README.pt-BR.md`](profile/README.pt-BR.md) é a tradução em português brasileiro, acessível pelo perfil em inglês.
- A aplicação, arquivos de release, issues e documentação para desenvolvedores ficam em [`Gravewright/gravewright`](https://github.com/Gravewright/gravewright).

Mantenha os dois perfis alinhados ao atualizar links de releases, requisitos ou descrições de funcionalidades. Use links absolutos do GitHub no perfil para que a navegação também funcione na página da organização. Confira as informações na documentação da aplicação e preserve a distinção de licenciamento entre o núcleo e os módulos independentes.

A localização do perfil segue a [documentação do GitHub para perfis de organizações](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).

A documentação deste repositório usa **GPL-3.0-only**; consulte [LICENSE](LICENSE). A permissão específica da aplicação para módulos e os termos de terceiros estão vinculados no perfil.
