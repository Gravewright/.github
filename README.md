# Gravewright organization profile

[English](README.md) · [Português (Brasil)](README.pt-BR.md)

This repository maintains the public presentation of the [Gravewright organization](https://github.com/Gravewright).

- [`profile/README.md`](profile/README.md) is the primary English profile shown on the organization's overview page.
- [`profile/README.pt-BR.md`](profile/README.pt-BR.md) is the Brazilian Portuguese translation, linked from the English profile.
- The application, release assets, issue tracker and developer documentation live in [`Gravewright/gravewright`](https://github.com/Gravewright/gravewright).

Keep both profile files aligned when updating release links, requirements or feature descriptions. Use absolute GitHub links in the profile so navigation also works from the organization overview. Check product claims against the application documentation and keep its licensing distinction between core code and independent modules.

The profile location follows [GitHub's organization profile documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).
